# 브랜드 레시피 스튜디오

AI 호출 없이 저장된 규칙으로 로고와 명함을 추천·수정·저장하는 정적 웹 베타입니다.

## 현재 기능

- 6개 편집 가능 로고 레시피와 규칙 기반 추천
- 브랜드명·설명 문구·색상·크기·간격 수정
- 선택 요소 고정, 단순화, 색상만 변경
- 양면 명함 미리보기와 연락 정보 수정
- 브라우저 저장, SVG·PNG 다운로드, PDF 인쇄
- 모바일 편집 화면

AI 마감 버튼은 기능 경계를 확인하기 위한 자리이며 외부 AI를 호출하지 않습니다.

화면의 기본 연락처와 이름은 설명용 가상 정보입니다. 사용자가 입력한 정보는 브라우저의 로컬 저장소에만 저장됩니다.
