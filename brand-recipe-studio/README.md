# 브랜드 레시피 스튜디오

회사명·사업 설명·제11차 한국표준산업분류 대분류를 바탕으로 AI 호출 없이 로고를 추천하고, 추천 후 직접 수정하는 정적 웹 베타입니다.

- 조합형 로고 레시피 150개(심볼 10 × 레이아웃 5 × 표현 3). 독립 원안 150개가 아님
- 양면 명함 레시피 289개(앞면 구조 17 × 뒷면 구조 17)
- 컬러 시스템 30개와 21개 산업군 × 5개 인상별 추천 규칙
- 추천 12개 보기 / 전체 150개 직접 선택
- 로고 요소와 명함 정보의 마우스·터치 드래그
- 명함 앞면·뒷면 동시 미리보기와 도련·재단·안전영역 표시 토글
- 홈 대시보드와 브라우저별 `내 작업` 저장 목록
- 저장 작업 다시 열기·복제·삭제와 마지막 저장본 복원
- 편집 실행취소·다시실행(최대 60단계) 및 현재 배치 초기화
- SVG·PNG·브라우저 인쇄 PDF 내보내기
- 브라우저 자동 저장, 최종 단계 AI 연결 자리만 분리

AI 호출 없이 저장된 규칙으로 로고와 명함을 추천·수정·저장하는 내부 검증 베타입니다. 상용 출시는 독립 디자인 원안 확충과 사용자 검증 전까지 보류합니다.

## 현재 기능

- 업종·인상을 바꾸면 심볼·구도·색상·추천 사유가 함께 갱신
- 추천 상위 12개 시각 중복 제거, 상위 6개 심볼 방향 분산
- 브랜드명·설명 문구·색상·크기·간격 수정
- 선택 요소 고정, 단순화, 색상만 변경
- 양면 명함 미리보기와 연락 정보 수정
- 브라우저 저장, SVG·PNG 다운로드, PDF 인쇄
- 모바일 편집 화면

AI 마감 버튼은 기능 경계를 확인하기 위한 자리이며 외부 AI를 호출하지 않습니다.

## QA 게이트

`node tests/recommendation-smoke.js`

- 21개 산업군 × 5개 인상 = 105개 조합 전수 검사
- 추천 상위 12개 ID·SVG 중복 없음
- 상위 6개 서로 다른 심볼, 레이아웃 3종 이상, 표현 2종 이상
- 명함 상위 6개 앞면 구조 분산
- 직접 선택 모드에서 업종·인상 변경 시 선택 레시피 유지

실제 화면 검수는 데스크톱·모바일에서 업종/인상 변경, 양면 명함, 인쇄 가이드, 저장·복원·실행취소 흐름을 확인해야 합니다.

화면의 기본 연락처와 이름은 설명용 가상 정보입니다. 사용자가 입력한 정보는 브라우저의 로컬 저장소에만 저장됩니다.
