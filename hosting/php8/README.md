# 잡앤킬 진학설계 — PHP 서버 이관 준비본

기존 Node 사이트의 화면과 데이터 조회 기능을 PHP 8.0 이상 / MariaDB 10.x 환경에서 실행하기 위한 패키지입니다. 개선된 디자인은 홈페이지 검토 파일에서 확인할 수 있습니다. 현재 Render 주소에 새 디자인을 반영하는 작업과 소유 서버 이관은 디자인 확정 후 진행합니다. 승인 후 실제 호스팅의 경로와 DB 정보를 반영하고 설치 점검을 마친 최종 이관 파일을 전달합니다.

## 생성

개발 환경에서 `npm ci` 후 `node scripts/build-php-hosting.mjs /원하는/출력/경로`를 실행합니다. 출력 파일에는 npm이나 Node 실행 환경이 필요하지 않습니다. 기존 데이터를 복사하고 입결 데이터를 대학별 파일로 분할합니다. PDF.js, 글꼴, 이미지도 함께 복사합니다.

## 파일 배치

```text
호스팅 계정 폴더/
  public_html/        ← 웹에서 공개되는 파일
    index.html
    index.php
    .htaccess
    assets/
    vendor/
    ...
  private_app/        ← 웹 루트 밖의 비공개 파일
    bootstrap.php
    document-proxy.php
    config.example.php
    consultations.sql
    data/
    storage/documents/
```

서버의 웹 루트 이름이 `www`, `html` 등인 경우 `public_html` 안의 파일을 그 웹 루트에 복사합니다. `private_app`은 해당 웹 루트의 바로 위 폴더에 배치합니다. 웹 루트 밖에 파일을 둘 수 없는 호스팅은 현재 배치를 그대로 사용하지 말고, 비공개 경로와 접근 차단을 호스팅 환경에 맞춰 조정해야 합니다. `.htaccess` 파일도 빠짐없이 업로드합니다.

필요 조건은 Apache의 `mod_rewrite` 및 `.htaccess` 허용, PHP 확장 `pdo_mysql`, `curl`, `mbstring`, 권장 PHP 메모리 128MB 이상입니다. Nginx 서버는 `.htaccess` 대신 PHP front controller 규칙과 비공개 파일 접근 차단을 서버 설정에 작성해야 합니다. URL 하위 경로에 설치할 때에도 화면의 API 및 자료 주소는 상대 경로로 생성됩니다.

## DB 및 상담 신청

1. MariaDB 데이터베이스와 해당 DB에 접근하는 계정을 만듭니다.
2. phpMyAdmin 등에서 `private_app/consultations.sql`을 실행합니다.
3. `config.example.php`를 `config.php`로 복사하고 호스팅에서 받은 DB 호스트, 포트, DB명, 사용자명, 비밀번호를 입력합니다.
4. `/api/health`의 `consultationsReady`가 `true`인지 확인하고 상담 신청 한 건이 DB에 저장되는지 확인합니다.

DB 설정이 없으면 대학 탐색과 연습 화면은 동작하지만 상담 제출에는 오류를 반환합니다. 실제 저장 없이 신청 완료를 표시하지 않습니다. 별도 자기소개서 서비스로 연결하려면 `resume_writer_url`에 해당 HTTPS 주소를 입력합니다.

`storage/documents`에 PHP 프로세스가 쓸 수 있으면 공식 PDF를 캐시합니다. 캐시가 쓰기 불가능한 경우에도 조회를 시도합니다. 원문 사이트로의 HTTPS 통신과 DNS 조회가 호스팅에서 허용되어야 PDF를 읽을 수 있습니다.

## 이관 시 데이터 확인

- 대학·학과·입결 데이터는 패키지의 스냅샷입니다. 화면에 각 자료의 실제 기준연도와 출처를 표시합니다.
- 성적, 지원 후보와 연습 기록은 기존처럼 브라우저에 저장됩니다. 도메인이 바뀌면 기존 도메인의 브라우저 기록이 새 도메인으로 자동 복사되지 않습니다. 기존 화면의 백업·내보내기 제공 범위와 필요한 기록을 전환 전에 확인해야 합니다.
- 기존 운영 DB의 상담 신청 기록은 이 패키지에 포함되지 않습니다. 보존이 필요하면 별도 DB 내보내기 및 MariaDB 변환을 진행합니다.
- 공개 대학 목록과 상세 전형 데이터의 제공 범위는 다릅니다. 목록에 포함된 모든 대학에 상세 모집요강이나 상담 검증 자료가 있는 것은 아닙니다.

## 검증 범위

프런트엔드의 87개 기존 검사를 통과했습니다. Node API와 PHP API의 25개 조회 결과를 비교했고, MariaDB 10.11.14에서 상담 저장과 조회를 확인했습니다. PHP 8.0 문법 파서 검사를 통과했으며 실제 실행 검증 환경은 PHP 8.3.6입니다. PC와 320·390·768px 화면에서 대학 검색, 후보 저장, 성적 입력 및 모바일 메뉴를 확인했습니다.

실제 아이비호스팅의 PHP 설정, 파일 권한, URL 재작성, 외부 PDF 통신은 설치 시 다시 확인합니다. `dev-router.php`는 로컬 개발용이므로 서버에 업로드할 필요가 없습니다. 글꼴 및 PDF.js 라이선스 파일은 패키지에 포함되어 있습니다.
