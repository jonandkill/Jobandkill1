# Job&Kill 네이버 블로그 스튜디오

영상·메모·조사 자료로 작성한 대본을 **네이버 블로그 게시 직전 묶음으로 자동 정리하고, 사람이 마지막 확인·붙여넣기·발행하는** 독립형 웹 도구입니다.

현재 버전은 `1.1.0`입니다. 대본을 한 번 입력하면 제목 후보, 목차, 본문 구조, 이미지 배치안, 대체텍스트, 품질 점검과 게시 대기열을 함께 만듭니다.

## 왜 반자동 방식인가

첨부된 참고 영상은 별도 프로그램이 로그인 세션을 복원한 뒤 네이버 스마트에디터에 본문과 이미지를 직접 입력합니다. 키 입력 간격을 임의로 바꾸더라도 자동 조작이라는 성격은 달라지지 않습니다.

네이버는 외부 서비스가 글을 등록하던 로그인 방식 블로그 글쓰기 API를 2020년 5월 6일 종료했습니다. 종료 공지는 반복적·기계적으로 유사한 글을 대량 발행하는 오용을 이유로 들고 있습니다.

- 공식 공지: <https://developers.naver.com/notice/article/7527>

이 프로젝트에는 다음 기능을 넣지 않습니다.

- 네이버 자동 로그인 또는 세션·쿠키 재사용
- Selenium, Playwright, Puppeteer, PyAutoGUI 등의 편집기 조작
- 키 입력 시뮬레이션과 랜덤 지연을 이용한 탐지 회피
- 예약·대량 자동 발행
- 계정 비밀번호나 인증정보 저장

## 구현 기능

- 대본 원문 보존 기반 제목 후보 3개와 제목·도입부·소제목·출처·태그 분리
- 소제목 순서를 반영한 자동 목차
- 소제목이 없는 원고의 보수적 문단 묶음
- 제목 길이, 본문 분량, 대표 키워드, 소제목, 출처, 과장 표현, 긴 문단, 중복 문장 점검
- 대표·본문 이미지의 위치, 제작 지시문, 대체텍스트 계획 자동 구성
- 일반 텍스트 복사, 제목·목차·본문 서식을 유지하는 한 번 복사, 구역별 복사
- 앱 안에서만 동작하는 검수 재생과 속도 조절
- 브라우저 자동 저장, JSON 불러오기·내보내기, Markdown 내보내기
- 발행 예정 시각과 `검수 대기 → 발행 승인 → 게시 완료` 상태를 기록하는 로컬 대기열
- 네이버 블로그 새 탭 열기 전 4개 사람 확인 체크리스트
- 네트워크 호출·외부 의존성·브라우저 저장 자격증명 없음

게시 예정 시각은 관리용 메모입니다. 시간이 되어도 백그라운드에서 네이버를 열거나 글을 발행하지 않습니다.

### 단축키

| 단축키 | 동작 |
|---|---|
| `Alt+1` | 제목을 클립보드에 복사 |
| `Alt+2` | 도입부를 클립보드에 복사 |
| `Alt+3` | 현재 선택된 소제목 구역 복사 |
| `Alt+←` / `Alt+→` | 소제목 구역 이동 |
| `Alt+4` | 본문 전체 복사 |
| `Alt+5` / `Alt+6` | 태그 / 참고자료 복사 |
| `Space` | 앱 내부 검수 재생·일시정지 |
| `Esc` | 검수 재생 중지 |
| `[` / `]` | 검수 표시 속도 느리게 / 빠르게 |

단축키는 사용자가 이 앱을 보고 있을 때만 작동하며 다른 브라우저 탭이나 프로그램에 키를 보내지 않습니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행할 수 있습니다.

```bash
npm start
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다.

## 검증

```bash
npm run check
npm test
```

## 운영 원칙

1. 수치·날짜·규제·채용 일정은 공식 출처와 대조합니다.
2. 원문에 없는 체험담, 후기, 순위, 수익·합격 보장을 만들지 않습니다.
3. 이미지마다 사용권과 대체텍스트를 확인합니다.
4. 협찬·광고·이해관계가 있다면 글 안에 표시합니다.
5. 네이버 편집기에서 최종 내용과 공개 범위를 사람이 확인한 뒤 발행합니다.

내부 품질 점수는 편집 누락을 찾기 위한 체크리스트이며 네이버 검색 노출이나 순위를 예측·보장하지 않습니다.
