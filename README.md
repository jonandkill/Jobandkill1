# 잡앤킬 수시설계

## 전국 자료 확장과 입결 비교

2026-09-09 개편은 대학 기본정보·지원현황, 논술 자료실·개별 원문, 연도별 입결을 각각 구분한다. `/api/catalog`는 대학 목록과 입결 보유 대학 요약을 제공하고, `/api/outcomes?universityId=0000158`는 선택한 대학의 입결만 반환한다. 최신 집계는 `data/coverage.json`에 기록한다. `completeUniversities`는 모든 전형별 필수 항목 검수 완료 수이므로 기본정보 수집 수와 다르다.

관리자 자료 수집은 Python 3, curl, `requirements-collector.txt`의 lxml 환경에서 수행한다. 수집기의 원문 캐시는 저장소 밖에 두며, 대학 공식 페이지가 명시한 성적 지표만 추출한다. 지원 인원과 실제 합격 통보 인원을 함께 확인한 경우에만 관측 합격 비율 계산 함수가 값을 반환한다. 모집인원이나 예비번호를 합격자 수로 대체하지 않는다. 현재 공개 입결만으로 개인 합격확률 모델이 검증되었다고 표시하지 않는다.

```bash
python scripts/collect-adiga-details.py
python scripts/publish-adiga-details.py
python scripts/collect-adiga-departments.py
python scripts/collect-outcomes.py --workers 3
node scripts/sync-coverage.mjs
node scripts/pack-outcomes.mjs
npm run check:data
npm test
python -m unittest discover -s tests -p 'test_*.py'
```

논술 원문은 확인된 대학 공식 파일을 열람하도록 연결하며, 게시판 링크만 확보한 항목을 기출 본문 수록으로 계산하지 않는다. 실제 수험생 사용성 검수 계획은 `USER_ACCEPTANCE.md`에 별도로 기록한다.

입결 배포 파일은 `data/outcomes.json.gz`이다. 압축 해제 전후 바이트 일치를 확인해 원본 수치를 그대로 보존한다. 수집 작업에서는 `outcomes.json`을 사용하고 운영 서버는 원본 파일이 없으면 압축본을 읽는다. 압축은 데이터량을 줄이는 저장 방식이며 자료를 요약하거나 표본을 줄이지 않는다.

2027학년도 공식 대학 목록과 대학별 수시 모집요강에서 검수한 조건을 사용하고, 수능최저 조건을 규칙으로 판정하는 웹 솔루션이다. 외부 AI 서비스가 없어도 전국 대학 검색, 학과 검색, 연도별 입결 조회, 필터, 조건 계산, 최대 3개 전형 비교와 기본 보고서가 작동한다. PostgreSQL 연결은 선택 사항이며 현재 배포는 파일 데이터로도 동작한다.

## 데이터 범위

- 대입정보포털 어디가 2027학년도 일반대학 220개 캠퍼스 항목
- 대입정보포털 어디가 2027학년도 전문대학 132개 캠퍼스 항목
- 한양대학교 서울캠퍼스·연세대학교 서울캠퍼스·성균관대학교·서강대학교 상세 전형

초기 규칙 DB는 상세 전형 묶음 17건, 자동판정 규칙 11건으로 구성한다. 공식 검색의 352개 대학·캠퍼스 항목에는 과거 폐교·통합 항목도 포함되므로 현재 지원 가능한 대학 수로 해석하지 않는다. 확인된 폐교·통합 학교는 현재 탐색에서 제외하고 과거 입결로 접근한다. 전체 대학의 기본 현황과 상세 전형 검수 상태를 분리하며, 검수되지 않은 규칙은 자동 계산하지 않는다. 학생부종합과 학생부교과의 정성평가 및 추천 자격도 자동 합격 가능성을 산출하지 않는다.

## 공식 목록 갱신

## 재기획 적용 범위

평균 내신은 프로필에 보관하는 탐색 참고값이다. 입결은 동일 대학·모집단위·전형의 연도별 자료를 나란히 보여주고, 산출 방식까지 검증된 경우에만 범위와 대학 환산 성적 차이를 계산한다. 기존 수능최저 계산과 구분한다. `data/details.json`에는 전국 기본 연락처와 확인된 지원현황·공식 문서 위치를 담고, `data/extra-details.json`에는 페이지별 수집한 학과 목록과 수집 완결 상태를 담는다. `/api/departments`는 학과 검색 및 대학별 상세 조회를 제공한다. 자료에 없는 항목은 추정하지 않는다.

회원 서버 저장과 상담 접수는 별도 연동 사항이다. 기기 내 저장이나 상담 초안 다운로드를 실제 상담 접수로 표현하지 않는다.

## 실행 방법

```bash
npm ci
npm start
```

`DATABASE_URL`이 있으면 PostgreSQL 테이블을 만들고 검수 데이터를 갱신한다. 설정하지 않으면 동일한 검수 파일을 읽어 기능을 유지한다. 학생이 입력한 성적은 브라우저의 로컬 저장소에만 보관한다.

## 2026-09-10 v3: 학교 탐색·평균 계산·실전 연습

이번 개편은 학교 카드부터 보여주는 탐색, 선택 세부성적 평균 계산, 실제 문항·PDF 읽기, 타이머, 기준답안 비교, 단일 면접 답변을 연결한다.

- `#recommend`: 학교 카드 12개/쪽 → 선택 학교의 학과·전형 5개/쪽. 전국 초기화, 별칭/특수법대학 검색. 전체 평균으로 개인 합격확률이나 임의 합격 순위를 만들지 않는다.
- 최초 입력 2단계와 입결 탐색의 선택 세부성적: 소수점 둘째 자리, 과목·학기 추가, 단순/이수단위 가중평균, 계산값 적용. 단위 일부 누락과 5·9등급 체계 불일치는 계산을 보류한다.
- `#prepare/essay`: 자체 출제 24문항 + 공식 자료 연결 수치 문항 4개(실제 기출 3, 모의 1). 자체 문제 본문·참고답안·기준을 제공하며 공식 기출로 표시하지 않는다. 수치 답은 확인된 최종값 배점만 계산한다. 서술 답은 작성 문장 인용과 기준별 수정 피드백이다.
- PDF.js로 공식 PDF를 내부 캔버스에 표시하고 중앙 이전/다음·쪽수 이동·전체 쪽수·내려받기를 제공한다. 대학 서버 접근 실패는 안내하며 빈 iframe을 성공 상태로 표시하지 않는다.
- 공식 시간 근거가 연결된 문항은 시험 전체 시간을 기본값으로 제공한다. 나머지는 명시한 자유 연습 시간이다. 시작/일시정지/재설정, 닫았다 돌아와도 절대 종료시각으로 잔여시간을 계산한다.
- 면접은 단일 자유 답변 → 실제 문장 근거 → 개선 제안. 학교·학과별 자체 연습 질문과 공식 안내를 구분한다. TXT/PDF는 브라우저에서 읽어 질문을 만들며 파일을 서버나 AI에 업로드하지 않는다.
- 교육자료 1,995행 중 학부·전문대 442행을 수집·보존했다. 폐교·구교명 등이 있어 모두 현재 수시 모집학교로 합치지 않는다. 별도 공식 확인한 누락 학교 8개를 탐색 목록에 추가했다.

실행은 Node 22.13 이상 및 `npm ci`가 필요하다. PDF.js 버전은 잠금 파일로 고정한다. `RESUME_WRITER_URL`에 교수님이 개발한 자기소개서 작성 서비스의 실제 HTTPS 주소를 설정하면 면접 페이지에 연결된다. 주소가 없을 때 다른 사이트로 임의 연결하지 않는다.

PDF 중계는 자료 ID 허용목록, 공개 DNS 검사, 같은 호스트 리디렉션 제한, 40MB 제한 및 제한된 메모리 캐시를 적용한다. 사용자 임의 URL을 받아 가져오지 않는다. 운영은 기존 Render Node 서비스이며 아이비호스팅 PHP 8.0에서 이 Node 서버를 그대로 실행하는 구조가 아니다.

검수·한계: `EVALUATION_PROTOCOL.md`, `REGISTRY_QA_V3.md`, `LIFECYCLE_DESIGN.md`, `USER_ACCEPTANCE.md`. 전문 서술 채점 정확도, 전국 모든 전형·기출 원문, 실제 사용자 참여 검수는 완료됐다고 주장하지 않는다.


## 내부 경험 정리·글 작성 통합

`#prepare/writing` 또는 상단 '경험·글 작성' 메뉴에서 실제 경험 → 직접 한 행동 → 결과·배움 → 작성문 확인의 4단계 편집기를 제공한다. 면접 준비 안에서도 같은 편집기를 열 수 있다. 기존 잡앤킬 자기소개서 서비스의 문장 구성 엔진을 재사용하며 출처·원본 커밋·해시는 `WRITING_ENGINE_PROVENANCE.md`에 기록한다. 기본 글 구성·구조 피드백·질문 생성은 외부 AI나 서버 업로드 없이 브라우저에서 동작한다.

사용자가 확인한 글을 '이 글로 면접 질문 만들기'로 전달하면 기존 학교·학과 맞춤 면접 연습으로 연결된다. 작성문은 직접 수정하거나 TXT로 내려받을 수 있다. 입력 원문을 그대로 모으는 기능과 문장 흐름을 다듬는 기능을 구분한다. 없는 활동·결과·수치를 생성하지 않도록 변환 결과를 원문과 대조한다.

초안은 탭 안에서 이동할 때 보존되며 기기 저장을 선택하면 같은 브라우저의 새로고침 후에도 복원한다. 대학·학과도 함께 복원하되 직접 입력 학과와 공식 수집 학과를 구분한다. 자기소개서 원문 질문·답변은 서버나 회원 계정에 저장하지 않는다. 이 탭에서 최근 글 5개까지 답변을 보존해 원문 재적용 시 복원한다. 첨부 원문 저장 정책은 유지한다.

기존 자기소개서 서비스의 회원·경험은행·초안 버전 동기화까지 통합한 것은 아니다. 기존 보관함은 선택적인 외부 경로로 남고 현재 수시 사이트의 기본 작성은 사이트 안에서 끝난다.
