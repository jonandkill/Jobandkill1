# 잡앤킬 수시설계

2027학년도 대학별 공식 수시 모집요강에서 검수한 조건을 PostgreSQL에 적재하고, 수능최저 조건을 규칙으로 판정하는 웹 솔루션이다. 외부 AI 서비스가 없어도 검색, 필터, 조건 계산, 최대 3개 전형 비교와 기본 보고서가 작동한다.

## 데이터 범위

- 한양대학교 서울캠퍼스
- 연세대학교 서울캠퍼스
- 성균관대학교
- 서강대학교

초기 DB는 공식 문서 4건, 전형 묶음 17건, 자동판정 규칙 11건으로 구성한다. 학생부종합과 학생부교과의 정성평가 및 추천 자격은 자동 합격 가능성을 산출하지 않는다.

## 실행

```bash
npm ci
npm start
```

`DATABASE_URL`이 있으면 PostgreSQL 테이블을 만들고 검수 데이터를 갱신한다. 설정하지 않으면 동일한 검수 파일을 읽어 기능을 유지한다. 학생이 입력한 성적은 브라우저의 로컬 저장소에만 보관한다.

## 확인

```bash
npm run check:data
npm test
```
