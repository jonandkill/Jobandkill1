# 잡앤킬 수시설계

## 전국 자료 확장과 입결 비교

2026-09-09 개편은 대학 기본정보·지원현황, 논술 자료실·개별 원문, 연도별 입결을 각각 구분한다. `/api/catalog`는 대학 목록과 입결 보유 대학 요약을 제공하고, `/api/outcomes?universityId=0000158`는 선택한 대학의 입결만 반환한다. 최신 집계는 `data/coverage.json`에 기록한다. `completeUniversities`는 모든 전형별 필수 항목 검수 완료 수이므로 기본정보 수집 수와 다르다.

관리자 자료 수집은 Python 3, curl, `requirements-collector.txt`의 lxml 환경에서 수행한다. 수집기의 원문 캐시는 저장소 밖에 두며, 대학 공식 페이지가 명시한 성적 지표만 추출한다. 지원 인원과 실제 합격 통보 인원을 함께 확인한 경우에만 관측 합격 비율 계산 함수가 값을 반환한다. 모집인원이나 예비번호를 합격자 수로 대체하지 않는다. 현재 공개 입결만으로 개인 합격확률 모델이 검증되었다고 표시하지 않는다.

```bash
python scripts/collect-adiga-details.py
python scripts/publish-adiga-details.py
python scripts/collect-adiga-departments.py
python scripts/collect-outcomes.py --workers 3
node scripts/sync-coverage.mjs
node scripts/pack-outcomes.mjs
npm run check:data
npm test
python -m unittest discover -s tests -p 'test_*.py'
```

논술 원문은 확인된 대학 공식 파일을 열람하도록 연결하며, 게시판 링크만 확보한 항목을 기출 본문 수록으로 계산하지 않는다. 실제 수험생 사용성 검수 계획은 `USER_ACCEPTANCE.md`에 별도로 기록한다.

입결 배포 파일은 `data/outcomes.json.gz`이다. 압축 해제 전후 바이트 일치를 확인해 원본 수치를 그대로 보존한다. 수집 작업에서는 `outcomes.json`을 사용하고 운영 서버는 원본 파일이 없으면 압축본을 읽는다. 압축은 데이터량을 줄이는 저장 방식이며 자료를 요약하거나 표본을 줄이지 않는다.

2027학년도 공식 대학 목록과 대학별 수시 모집요강에서 검수한 조건을 사용하고, 수능최저 조건을 규칙으로 판정하는 웹 솔루션이다. 외부 AI 서비스가 없어도 전국 대학 검색, 학과 검색, 연도별 입결 조회, 필터, 조건 계산, 최대 3개 전형 비교와 기본 보고서가 작동한다. PostgreSQL 연결은 선택 사항이며 현재 배포는 파일 데이터로도 동작한다.

## 데이터 범위

- 대입정보포털 어디가 2027학년도 일반대학 220개 캠퍼스 항목
- 대입정보포털 어디가 2027학년도 전문대학 132개 캠퍼스 항목
- 한양대학교 서울캠퍼스·연세대학교 서울캠퍼스·성균관대학교·서강대학교 상세 전형

초기 규칙 DB는 상세 전형 묶음 17건, 자동판정 규칙 11건으로 구성한다. 공식 검색의 352개 대학·캠퍼스 항목에는 과거 폐교·통합 항목도 포함되므로 현재 지원 가능한 대학 수로 해석하지 않는다. 확인된 폐교·통합 학교는 현재 탐색에서 제외하고 과거 입결로 접근한다. 전체 대학의 기본 현황과 상세 전형 검수 상태를 분리하며, 검수되지 않은 규칙은 자동 계산하지 않는다. 학생부종합과 학생부교과의 정성평가 및 추천 자격도 자동 합격 가능성을 산출하지 않는다.

## 공식 목록 갱신

어디가 대학 검색 결과 HTML을 내려받은 뒤 아래 명령으로 정규화한다. 이 작업은 운영 서버 요청 시 실행하지 않고 관리자가 연도별로 수행한다.

```bash
npm run import:universities -- general-results.html college-results.html data/universities.json
```

## 재기획 적용 범위

평균 내신은 프로필에 보관하는 탐색 참고값이다. 입결은 동일 대학·모집단위·전형의 연도별 자료를 나란히 보여주고, 산출 방식까지 검증된 경우에만 범위와 대학 환산 성적 차이를 계산한다. 기존 수능최저 계산과 구분한다. `data/details.json`에는 전국 기본 연락처와 확인된 지원현황·공식 문서 위치를 담고, `data/extra-details.json`에는 페이지별 수집한 학과 목록과 수집 완결 상태를 담는다. `/api/departments`는 학과 검색 및 대학별 상세 조회를 제공한다. 자료에 없는 항목은 추정하지 않는다.

회원 서버 저장과 상담 접수는 별도 연동 사항이다. 기기 내 저장이나 상담 초안 다운로드를 실제 상담 접수로 표현하지 않는다.

## 실행 방법

```bash
npm ci
npm start
```

`DATABASE_URL`이 있으면 PostgreSQL 테이블을 만들고 검수 데이터를 갱신한다. 설정하지 않으면 동일한 검수 파일을 읽어 기능을 유지한다. 학생이 입력한 성적은 브라우저의 로컬 저장소에만 보관한다.

# 2026-09-10 추가 기능

- `#home`: 모션 홈, 상단 탐색 메뉴, 따라오는 지원 후보 도구.

- `#prepare/essay`: 공식 PDF 33개 연습 자료, 문항별 배점 행 209개, 답안 임시 저장·어려운 자료·자기평가 및 형식 피드백.
- `#prepare/interview`: 12개교 일부 전형 안내, 자체 연습 질문, 답변 구상과 구조 피드백.
- 논술 목록 중앙 이전/다음·현재/전체 페이지 표시.

개인 합격확률·검증된 합격 순위·논술 정답 자동채점은 제공하지 않는다. 회원 동기화와 검증된 면접 후기 수집은 미완료다. 데이터/검수 상세는 `ESSAY_PRACTICE_AUDIT.md`, `INTERVIEW_AUDIT.md`, `DESIGN_RESEARCH.md`, `USER_ACCEPTANCE.md`를 참조한다.
