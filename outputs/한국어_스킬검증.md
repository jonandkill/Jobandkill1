웹으로 Codex SKILL.md와 두 Python 원문을 열어 경로·입출력·import와 판정 규칙을 읽었다. 부모 담당은 GitHub connector에서 main commit b37e0206d31fffd9149bf57168d4d62eb2086bee, 버전 2.3.2 및 MIT 라이선스를 별도 확인했다. 이 담당의 웹 조회는 main 내용과 v2.3.2 태그 내용을 구분했다. main이 고정 태그와 항상 같다고 주장하지 않는다.

로컬 다운로드는 소켓 접근 권한 오류로 실패했다. 요구된 권한 재요청은 사용자가 중단했다. 따라서 다운로드된 원본 파일·로컬 SHA-256·스크립트 exit code·변경률은 없다. 빈 작업 디렉터리는 설치 증거가 아니다. 공개 코드에서 다른 Python 모듈과 참조 자료를 import하므로 verify_gates.py 한 파일만으로 실행 성공을 주장할 수 없다. 설치 스크립트는 실행하지 않았다.

## 적용할 원칙과 구분

공개 스킬은 문체 교정 중 사실·수치·고유명사·인용 등의 보존을 요구하고, 변경량이 과도한 결과를 보류하는 절차와 진단·윤문·검증 산출물을 명시한다. 운영안에는 이 의미 보존·원문 보존·구간별 교정 원칙을 반영했다. 원문을 읽고 운영 기준에 참고한 것이며, 이 문서 또는 150개 전체를 정식 스킬로 실행해 통과시켰다는 뜻이 아니다.

verify_gates.py의 수치는 문체와 변경량에 대한 기계적 경고다. 면접 조언의 타당성, 취업 효과, 신입 대상 적합성, 한국어 자연스러움을 보증하지 않는다. 코드 실행을 재개하면 고정 commit의 코드·의존 파일·라이선스 전체를 보존하고 정적 검토 후 작업 폴더에서만 실행한다. 설치·네트워크·사용자 설정 변경은 분리한다. 원본 입력과 교정본, hash, 실행 명령, stdout/stderr, exit code와 버전을 기록하고 오류를 pass로 바꾸지 않는다.

## 국립국어원 근거

공식 규범 포털 https://kornorms.korean.go.kr/regltn/regltnView.do?regltn_code=0001 은 이번 웹 도구에서 열리지 않았다. 이를 규범 열람 성공으로 기록하지 않는다. 대신 아래 공식 국립국어원 상담 페이지를 실제 조회했다.

1. 한글 맞춤법 제43항 상담(2026-08-31): https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=335208
   수 관형사와 단위 명사의 원칙적 띄어쓰기와 숫자·순서에 관한 허용을 구분한다. 운영 문구는 ‘다섯 개’, ‘한 명’, ‘네 시간’처럼 원칙을 따르며 ‘150개’ 등 숫자 표기는 일관되게 사용한다.
2. 단어 띄어쓰기 및 조사 상담: https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=326244&searchCondition=&searchKeyword=
   검색 결과에서 제2항과 제41항에 관한 공식 설명을 확인했다. 본문 전체를 열어 검토한 제43항 페이지와 확인 깊이가 다르다. 조사·의존 명사 등 개별 쟁점은 문맥에 따라 사전·규범 원문을 추가 확인한다.

## 자연스러움 검수 방법

각 문장을 ‘누가, 언제, 무엇을, 어떻게 하는가’로 풀어 쓸 수 있는지 확인한다. ‘기준으로 말하세요’처럼 기준의 실체가 없거나 ‘주도성’ 같은 추상 명사만 있으면 실제 행동으로 고친다. 면접 예시는 본인 역할·직접 한 일·확인 가능한 결과를 분리한다. 짧게 줄이면서 주어·대상·조건을 지우지 않는다. 낭독해 조사 연결과 문장 길이를 확인하고 원문과 교정문의 주장·대상·수치가 같은지 대조한다.

예시 교정은 의미 재설계가 필요한 사례와 단순 윤문을 구별한다. 모호한 제목을 명료한 질문으로 다시 기획한 작업을 ‘사실 보존 윤문만 했다’고 부르지 않는다. 현재 사용자 첨부 6장 실물에 대한 문장별 교정은 해당 이미지 확보·열람 증거가 필요하며 이 문서는 이를 대신하지 않는다.
